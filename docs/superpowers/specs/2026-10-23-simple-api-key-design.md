# Codex 首次连接：只填写一个 API Key

2026-10-23 用户已批准：使用本地设置页，安装后自动打开，用户只填写 API Key；实现并实际测试，通过后发布 GitHub。

## 体验

安装智能体自动打开“连接巴别鸟”页面，并在对话中留下可点击的填写入口。页面只含一个必填的 API Key 密码输入框、“保存并连接”按钮，以及没有密钥时的“打开巴别鸟获取”链接。服务地址、认证格式和本机配置由程序完成，不让用户阅读教程或寻找 MCP 菜单。

成功显示已连接，失败区分无效密钥、无权限、网络超时，允许原地重试。需要宿主重新加载时只说明一个明确动作。已有有效连接优先复用，不覆盖不同账号或其他 MCP 配置。

## 方式比较

原生安装密钥框操作最短，但 Codex 不执行 Claude userConfig 安装提示；手工 MCP 设置字段过多。用户选择自动打开的浏览器本地设置页。第一阶段只实现 Codex，WorkBuddy 保持已有流程，不能声称已适配或实测其自动配置。

## 边界

仅监听本机，使用临时凭证和同源校验。密钥只发给本机助手与 https://www.babel.cc/mcp，保存到用户私有配置区，不进入工程、聊天、安装包或日志。临时服务在成功或十分钟到期后退出。检查个人文件目录与一页列表，跳过配额，不上传工程。
