# 真实演示录制脚本 / Walkthrough script

状态：脚本已准备，审核视频尚未录制。必须用独立审核账号和公开示例文件操作；禁止用假的成功画面代替实际结果。

建议 4–6 分钟，按 [review-cases.json](review-cases.json) 操作并在结果表记录实际结果。使用公开示例 [fixtures/demo-project](fixtures/demo-project)，新建专门测试目录；不要展示私有工程或真实密钥。凭据填写时暂停录制，恢复后展示实际检查结果。

1. **安装和连接**：仅发送固定 GitHub 版本链接和安装要求。展示智能体主动打开页面、用户只填一项、检查成功及重启后连接可用。英文旁白：“Install from the GitHub link, enter your own API Key privately, and verify the connection.”
2. **首次同步**：绑定 demo-project，展示云端真实目录与原文件。英文旁白：“Project files keep their original folder structure.”
3. **修改后上传**：修改一个示例文件，展示同名文件更新、回读校验和无重复文件。
4. **换目录续接**：用第二个空本地目录绑定同一个云端目录，展示字节一致和继续修改。若演示 WorkBuddy，必须在实际已登录 WorkBuddy 中完成。
5. **权限与冲突**：展示已有 755 脚本被云端内容更新后仍可执行；双端修改时保留冲突。
6. **错误处理**：依次演示错误 Key（不显示值）、Git 子目录忽略规则、失败保留本地进度。不要为了录像删除真实用户数据。

| 用例 | 宿主与版本 | 实测日期 | 预期 | 实际结果 | 证据／视频时间点 |

公开审核视频应只有示例数据。上传后检查审核人员无需额外权限即可观看，再在提交平台填写真实 URL。本仓库不会自动发布录像或泄露审核凭据。
