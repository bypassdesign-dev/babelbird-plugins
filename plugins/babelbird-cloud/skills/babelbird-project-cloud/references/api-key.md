# 获取巴别鸟 API Key

完整图文步骤见 [巴别鸟官方 MCP 接入教程](https://www.babel.cc/public/babelwiki/zh/mcp-integration.html)。

1. 登录巴别鸟，进入“设置 > API秘钥”，选择“创建API密钥”，为应用命名，例如 Codex 或 WorkBuddy。
2. 按用途选择范围：“应用程序文件夹”只访问专用目录；“完整”覆盖用户原本有权访问的文件。默认保存到个人文件的 codex／workbuddy 工程目录时，密钥范围必须包含该目标。范围不足时由用户调整授权或明确其他目录，智能体不自动扩权。
3. 创建后打开 APP 详情，复制上方“APIKey”。高级选项中的 APP Key、APP Secret 不能替代它；也可复制页面生成的 AI 接入提示词到可信的私密会话。
4. 读取需要元数据和内容读取权限；创建目录、上传或更新还需相应写入权限。仅做只读连接测试时不要求写入。
5. 在宿主私密凭据入口填写。公有云 MCP 地址固定为 `https://www.babel.cc/mcp`；重置 Key 后只更新凭据，不更换地址。

本插件使用目录读取验证连接，配额查询默认跳过；教程中的配额查询示例不是本插件的必过检查。
