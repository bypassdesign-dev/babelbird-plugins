# 逐文件存储与恢复

## 工程目录

工程以普通文件和子目录保存，不创建 ZIP。默认结构：

```text
个人文件/
  codex/
    网站改版/
      src/
        app.ts
      package.json
  workbuddy/
    市场资料/
      文案.md
      图片/
        banner.png
```

`codex` 与 `workbuddy` 是宿主分区目录。用户指定目标时直接使用其目标作为工程根目录。工程名取本地根目录名，文件名和相对目录保持不变；不对源码文件加前缀，不把工程文件平铺到宿主目录。

按服务端真实返回的父目录 ID 逐级定位或创建目录。不能把斜杠路径整个传入 `createFolder.name`，也不能以文档示例中的 ID 代替实际结果。路径中每一项都是普通文件名，不能是 `.`、`..` 或包含分隔符的伪名称。

## 保存范围

纳入用户指定的源代码、资料、素材、依赖声明与锁文件、构建配置及必要说明。审阅 Git 状态和忽略规则；用户明确指定但被忽略的成果不能静默遗漏。

通常排除依赖安装目录、缓存、临时文件、旧备份和可重建产物；用户明确要求保存的交付物仍应纳入。密钥、`.env`、私钥及包含 token 的配置不默认上传；记录需在恢复时重新配置的变量名，不记录其真实值。

默认不包含 `.git` 历史、智能体账号、完整聊天记录、全局配置或外部目录。需要保存这些内容时先确定范围。当前目录传输只处理普通文件与目录，跳过符号链接及特殊文件，不跟随链接；记录跳过项，不声称完整保留了链接语义。

上传前记录每个文件的相对路径、字节数和 SHA-256；用于传输的文件 MD5 单独计算。哈希必须对应实际发送的字节。读取或上传期间文件发生变化时重新读取该文件并记录新版本，无法保持一致时报告该文件未完成。

## 本地清单与回执

同步脚本将目标绑定保存在本地 `.babelbird-sync.json`，将共同基线和进度保存在 `.babelbird-sync-state.json`，两者都排除上传，也不包含凭据。辅助状态不作为云端项目内容。至少记录：

| 字段 | 内容 |
| --- | --- |
| 工程 | 实际宿主、MCP 地址与云端工程目录 ID／路径 |
| 文件 | 相对路径、字节数、SHA-256、云端文件 ID |
| 状态 | 待上传、已上传、元数据已核对、内容已回读校验、失败或结果未知 |
| 排除项 | 跳过的相对路径及原因 |
| 时间 | 本次执行时间和最后验证时间 |

自动同步与跨设备绑定的具体流程见 [同步执行](sync.md)。这不是服务端接口 schema。回执不能包含 API Key、临时上传／下载 URL，也不默认上传用户本机的绝对路径信息。没有回读校验时保持相应状态；未知结果不得标为成功。中断后先核对云端实际状态，再续传未完成文件。

## 恢复规则

递归、分页列出全部子目录和文件，使用服务端的分页结束信息；没有结束标志时读取至空页，并检测重复页或循环目录 ID。不能将默认首页视为完整工程。

下载前将远端相对路径规范化，并确认最终路径仍在新建的恢复目录内。拒绝：

- 绝对路径、`..`、Windows 盘符、UNC 路径及含分隔符的伪文件名；
- 符号链接、硬链接、设备文件及其他特殊文件；
- 重复路径、大小写或 Unicode 规则冲突，以及文件与目录同名冲突；
- 循环目录、无法确定的文件类型或超出本地可用空间的内容。

恢复到新建的空目录，不自动覆盖已有工程，不执行下载文件中的脚本。逐文件使用下载地址获取原始字节，核对数量与大小；有可信的预期哈希时再验证内容。没有上传回执或可信服务端摘要时明确说明无法证明与上传时完全一致。

列出未恢复的依赖、私有配置、历史和失败文件。仅下载成功不代表工程已能启动。
